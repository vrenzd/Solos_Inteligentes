# Solos_Inteligentes
Desenvolver uma solução analítica ponta a ponta para a recomendação de plantio, baseada na leitura de sensores espectrais de solo. O sistema visa transformar atributos físico-químicos brutos extraídos da Brazilian Soil Spectral Library (BSSL) em inteligência acionável e autônoma diretamente no ambiente agrícola.
